## 📌 Sobre o Desafio

Este repositório foi desenvolvido como parte de um **Desafio de Projeto da [DIO (Digital Innovation One)](https://www.dio.me/)**, focado em **Engenharia de Prompt e Produtividade com Inteligência Artificial Generativa**.

### 💡 Contexto e Objetivo
No cotidiano profissional e pessoal, modelos de linguagem (LLMs) como ChatGPT, Claude e Gemini são aliados poderosos para automatizar tarefas repetitivas, organizar fluxos de trabalho e liberar foco mental para o que realmente importa. No entanto, a qualidade da resposta de uma IA é um reflexo direto da clareza e estrutura do comando (*prompt*) fornecido.

O objetivo deste projeto é aplicar uma **metodologia estruturada de 3 etapas** para a formulação de prompts profissionais:
1. **Definição de Intenção:** Alinhamento de objetivos, persona e público-alvo.
2. **Contexto e Restrições:** Definição de formatos, limites de escopo e diretrizes de estilo para evitar alucinações e ambiguidades.
3. **Consolidação e Refinamento:** Unificação dos elementos em um prompt definitivo, claro e pronto para execução.

🧱 Passo 1: Defina a intenção
Nesta etapa, você vai descrever o que quer que a IA faça e para quem.

✍️ O que fazer
O que você quer gerar? Para quem? Qual o resultado esperado?

📋 Modelo para você adaptar
Quero que a IA gere uma agenda de exercícios físicos de baixo impacto para um público sedentário, com média de idade de 35 anos, nível iniciante, com o objetivo de preparar o condicionamento físico para uma caminhada de 25km.

✨ Exemplo preenchido
Quero que a IA gere uma lista de tarefas para estudantes, com o objetivo de melhorar a organização dos estudos.

🧱 Passo 2: Adicione contexto e restrições
Nesta etapa, você vai detalhar como a resposta deve ser construída.

✍️ O que fazer
Qual estilo deseja? Tem limite de tamanho? O que deve evitar?

📋 Modelo para você adaptar
Considere o seguinte contexto: rotina de 3 dias por semana de treino. O conteúdo deve ser apresentado em forma de tabela. Evite termos complexos.

✨ Exemplo preenchido
Considere o seguinte contexto: rotina de estudos diária. O conteúdo deve ter formato de lista simples. Evite linguagem técnica.


🧱 Passo 3: Una tudo em um prompt final
Nesta etapa, você vai juntar todas as partes em um único prompt claro.

✍️ O que fazer
Revise tudo, conecte as ideias e escreva um único comando.

📋 Modelo para você adaptar
Quero que a IA gere uma agenda de exercícios físicos de baixo impacto para um público sedentário, com média de idade de 35 anos, nível iniciante, com o objetivo de preparar o condicionamento físico para uma caminhada de 25km. Considere o seguinte contexto: rotina de 3 dias por semana de treino. O conteúdo deve ser apresentado em forma de tabela. Evite termos complexos.

✨ Exemplo preenchido
Quero que a IA gere uma lista de tarefas para estudantes, com o objetivo de melhorar a organização dos estudos. Considere o seguinte contexto: rotina de estudos diária. O conteúdo deve ter formato de lista simples. Evite linguagem técnica.

☁️ Como entregar seu Desafio
Salve seu Prompt final em um arquivo .txt ou .md (no editor de sua preferência) e publique em um dos hosts aceitos pela DIO:

Opção 1, Google Drive (mais simples):

1) Faça upload do arquivo no seu Google Drive.
2) Clique com o botão direito sobre o arquivo e escolha Compartilhar.
3) Em Acesso geral, selecione Qualquer pessoa com o link.
4) Copie o link e cole no campo de submissão da DIO.

Opção 2, Git/GitHub (ótimo para praticar versionamento):

1) Crie uma conta gratuita no GitHub, caso ainda não tenha.
2) Crie um repositório público (ex: meus-desafios-criativos).
3) Adicione seu arquivo .md ao repositório (pode ser pelo próprio site, em Add file > Upload files).
4) Abra o arquivo no GitHub e copie o link da página (URL do navegador).
5) Cole o link no campo de submissão da DIO.
Dica: o .md no GitHub já é renderizado de forma bonita, sem precisar de nenhuma configuração extra.
