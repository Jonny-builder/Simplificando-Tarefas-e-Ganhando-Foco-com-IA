## 📌 Sobre o Desafio

Este repositório foi desenvolvido como parte de um **Desafio de Projeto da [DIO (Digital Innovation One)](https://www.dio.me/)**, focado em **Engenharia de Prompt e Produtividade com Inteligência Artificial Generativa**.

### 💡 Contexto e Objetivo
No cotidiano profissional e pessoal, modelos de linguagem (LLMs) como ChatGPT, Claude e Gemini são aliados poderosos para automatizar tarefas repetitivas, organizar fluxos de trabalho e liberar foco mental para o que realmente importa. No entanto, a qualidade da resposta de uma IA é um reflexo direto da clareza e estrutura do comando (*prompt*) fornecido.

O objetivo deste projeto é aplicar uma **metodologia estruturada de 3 etapas** para a formulação de prompts profissionais:
1. **Definição de Intenção:** Alinhamento de objetivos, persona e público-alvo.
2. **Contexto e Restrições:** Definição de formatos, limites de escopo e diretrizes de estilo para evitar alucinações e ambiguidades.
3. **Consolidação e Refinamento:** Unificação dos elementos em um prompt definitivo, claro e pronto para execução.
